# Contributing

Bug reports, feature requests and pull requests are welcome at
<https://github.com/dirkwa/signalk-gebco-charts>.

The build runs entirely in GitHub Actions; test workflow changes with a
`workflow_dispatch` run on your fork before opening a pull request.
